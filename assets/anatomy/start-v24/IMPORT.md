# 知镜图谱首屏资源 v24

使用现有 BodyParts3D 4.0 男性轻量几何和 Female Anatomy Blast 2.2 女性轻量几何。

- 保留 2,234 个男性和 2,353 个女性结构网格的稳定编号、名称与显示组；男性全身预览沿用原先的 988 个部件，女性预览覆盖全部 2,353 个部件。
- 首屏预览按部件做边折叠简化，男性 42,795 个三角面，女性 42,443 个三角面；小部件保留最小可选几何。
- 位置在各部件包围盒内量化为 16 位，法线量化为 8 位，使用 meshoptimizer 1.3.0 编码和 gzip 打包；仅用于首屏预览。按需加载的原始精细资源没有修改。
- 最小目录和几何同包请求，完整来源、组成关系与目录随后读取。每个批次包含稳定结构槽编号，选取、隐藏和颜色使用同一编号映射。
- 解码和精细网格批次合并在 Web Worker 中完成，浏览器主线程只提交合批后的缓冲。

来源与许可继续见 [原模型署名](/ATTRIBUTION.md)；meshoptimizer 使用 MIT，许可保存在本目录的 MESHOPT-LICENSE.md。

复现：在项目根目录运行 `node _tools/build_anatomy_start_v24.mjs`。依赖已安装于 D 盘工作区 tools/anatomy-build。
