# 影像噪声及 ROI 轮廓变化对定量测量稳定性的影响

## 科研问题与平台中的位置

本研究从医学影像定量分析中的可重复性问题出发：当图像噪声增加或勾画轮廓出现轻微变化时，哪些测量值相对稳定，哪些测量值会明显改变？知镜提供文献检索、上下文阅读与 AI 辅助解释，供使用者查找影像组学标准化与重复性研究；模拟实验室提供可控影像及 ROI 测量核心；统计结果、参数和研究判断则作为可复现记录保存。实验将这一工作流程具体化为一个计算任务。

本次计算直接调用网站现有的 `SimulationCore.image()`、`ResearchCore.features()` 与 `ResearchCore.dice()`，通过批处理脚本组织重复实验。三个逻辑职责为：研究设计与参数整理、计算执行、结果独立核验。AI 开发助手辅助确定对照关系、编写批处理和结果说明，实际数值由 JavaScript 与独立 Python 实现计算得到。网站本身没有自主发起此次完整实验，不能将该过程表述为自主多 Agent 科研系统。

## 可复现方法

使用脑、肝脏、血管三种数学合成模板，每张图为 512×512 像素，像素间距 0.35 mm。目标为长半轴 12 mm、短半轴 9.6 mm 的椭圆，目标相对背景增加 180 个合成灰度单位。将高斯噪声标准差设置为 0、5、15、30、60，每个条件使用随机种子 1—20。不同噪声水平下同一模板、同一种子对应相同标准化随机噪声场，构成配对计算。三种模板共生成 300 张图像。

对每张图像采用三种 ROI：原始目标真值、原始真值经一次四邻域腐蚀后的轮廓、原始真值经一次四邻域膨胀后的轮廓。结构元包含中心及上下左右四个像素；图像外视为背景。一个像素对应 0.35 mm 的轴向变化。这里的内缩和外扩是明确定义的形态学扰动，不是一个待训练的分割算法。每张图计算三个 ROI，共形成 900 次测量。

面积定义为 ROI 像素数乘以像素间距平方；灰度标准差为 ROI 内像素的总体标准差。灰度熵使用宽度 25、以 0 为锚点的固定离散区间，按 `-Σp log₂p` 计算。Dice 计算扰动 ROI 与已知原始目标的重叠。每组汇总 20 次计算的均值与样本标准差，均值 95% 置信区间使用自由度 19 的 t 分布；配对差值也按同样方法汇总。20 个种子是计算重复，不是患者样本。面积和 Dice 由固定掩膜决定，各次重复相同，所对应的区间不代表临床不确定性。

## 实际结果

### 噪声对各指标的影响

原始 ROI 在三个模板中的面积均为 361.9875 mm²。噪声从 0 增至 60 时，面积和 Dice 均保持不变，这是因为实验固定了 ROI；并不意味着分割算法在噪声中仍能正确工作。

无噪声时，脑、肝脏、血管目标区域的平均合成灰度分别为 210、255、185，ROI 内标准差和熵均为 0。噪声标准差为 60 时，三模板的平均 ROI 标准差分别为 60.105、59.571、60.060，95% 均值区间分别为 [59.727, 60.484]、[59.149, 59.993]、[59.751, 60.368]。其熵分别为 3.319、3.306、3.317 bit。指标变化与对合成噪声的预期相符。

噪声 60 相对噪声 0 的配对平均灰度差分别为：脑模板 +0.575（95% CI 0.035—1.114）、肝脏模板 +0.255（−0.301—0.811）、血管模板 −0.481（−1.162—0.200）。变化方向不一致，绝对幅度小于 0.6；这一有限种子结果应直接报告，不能写成平均灰度完全不变，也不能仅凭脑模板区间未跨 0 推广为噪声造成系统性偏移。

### 轮廓小幅变化对测量的影响

四邻域内缩一个像素后，面积降至 340.9175 mm²，相对原始 ROI 减少约 5.82%；外扩后面积增至 383.5475 mm²，增加约 5.96%。与原始真值的 Dice 分别为 0.9700 和 0.9711。Dice 同样接近 0.97，但面积变化方向相反。

在噪声标准差 15 时，三模板原始 ROI 的平均标准差均约 15；外扩一个像素后，平均灰度分别下降约 10.146、10.124、10.112，ROI 内标准差分别升至 44.207、44.077、44.076。原因是外扩轮廓纳入了低于目标灰度的背景区域，产生显著混合效应。内缩仍主要位于均一目标内，平均灰度变化较小。该对照说明：仅检视轮廓重叠度不足以判断定量测量是否稳定，仍应复核轮廓、面积与灰度统计。

### 独立计算核验

选取三个模板在噪声 0、15、60 且随机种子为 1 的图像，共 9 张图、27 个 ROI。使用 NumPy 独立计算面积、均值、总体标准差、熵与 Dice，使用 SciPy 的二值腐蚀/膨胀核对 ROI。所有对照通过，JavaScript 与 Python 的最大绝对误差为 1.0445×10⁻¹²。该差异属于浮点运算级别。

Node.js 对 300 张合成图生成及 900 次测量的单次批处理耗时约 7.52 秒；这一数字是本机批处理耗时，既不是网站首屏时间，也不是公网并发能力。

## 结论与反馈优化

第一，噪声与轮廓扰动影响不同：固定轮廓下噪声主要改变灰度分布，而轮廓变化还会直接改变面积，并可能混入周围组织。第二，Dice 接近不等于测量值接近，约 0.97 的 Dice 在本例中仍伴随约 6% 面积差异。第三，明确像素间距、轮廓定义、离散化方式和随机种子，是解释结果与复跑结果的必要条件。

据此，知镜的科研工作流可以引导使用者先核对文献中的参数定义，再运行对照实验，同时保存 ROI、参数和原始数据；AI 解读需要引用实际结果，并回查是否把高 Dice 误解为所有指标稳定。下一轮可比较不同目标尺寸、多个像素间距和多档轮廓偏移，并在具有参考分割的真实公开数据上重复评估。

本研究是合成影像的受控计算实验，目标区域近似均一，没有模拟真实 CT 的空间相关噪声、重建核和完整部分容积过程。三个模板的目标形状相同，背景和位置不同，不能等同于三个临床队列。固定分箱锚点还会影响小噪声条件的熵，因此熵应连同离散规则解释，而非作为通用噪声计。
