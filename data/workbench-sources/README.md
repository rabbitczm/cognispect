# Research Workbench Sources

Official reference pages returned HTTP 200 on 2026-11-14. The verification receipt stores each URL, snapshot file size and SHA-256 of the corresponding local UTF-8 HTML capture, plus selected identifying or methodological excerpts. Full local snapshots are kept here for audit; the release ZIP omits those `.html` snapshots.

- CONSORT: the EQUATOR Network page identifies the current statement as **CONSORT 2025**. HELIX shows selected items for manual review, not the full checklist.
- STROBE: the EQUATOR Network page provides separate cohort, case-control, and cross-sectional checklists. HELIX shows a short set of shared review prompts, not a replacement for those checklists.
- PRISMA: the EQUATOR Network page points to the **PRISMA 2020** statement and official checklist. HELIX shows selected review prompts, not the full checklist.
- SciPy `bootstrap`: the official reference describes percentile, basic, and BCa interval methods. HELIX's sensitivity output is specifically the independently resampled percentile interval, with the random seed shown.
- SciPy `mannwhitneyu`: the official reference defines this as a two-independent-sample rank test and cautions that location interpretation depends on distribution shape.
- Chart.js mixed charts: consulted for mixed chart interaction patterns; HELIX draws its plots with its existing local SVG implementation and does not depend on Chart.js.

All checklist states remain researcher-entered. They are not research-quality scores or evidence that underlying data are authentic.
